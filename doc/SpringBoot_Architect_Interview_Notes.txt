2. Spring Boot

What is Spring Boot?

Spring Boot is an opinionated extension of Spring Framework that reduces
configuration and accelerates development through auto-configuration and
starter dependencies.

Spring Framework vs Spring Boot

Spring Framework: - Requires manual configuration. - XML/Java
configuration. - Manual dependency management.

Spring Boot: - Auto Configuration. - Embedded Tomcat/Jetty. - Starter
dependencies. - Production-ready Actuator. - Rapid development.

Key Features

-   AutoConfiguration
-   Starter Dependencies
-   Spring Boot CLI
-   Embedded Servers
-   Actuator
-   Externalized Configuration

@RestController and @RequestMapping

@RestController: - Combines @Controller + @ResponseBody. - Returns
JSON/XML directly.

@RequestMapping: - Maps requests to controllers.

Example:

    @RestController
    @RequestMapping("/api/products")
    public class ProductController {

        @GetMapping("/{id}")
        public Product getProduct(@PathVariable Long id){
            return service.findById(id);
        }
    }

RestTemplate Real World Customizations

    @Bean
    public RestTemplate restTemplate() {
        RestTemplate rt = new RestTemplate();

        rt.setInterceptors(List.of(new LoggingInterceptor()));

        return rt;
    }

Common Customizations: - Connection pooling - Timeouts - Logging
interceptors - Retry logic - OAuth/JWT headers - Error handlers -
Metrics and tracing - SSL customization

Pageable vs Slice

Page: - Total records available. - Executes COUNT query.

Slice: - Knows only if next page exists. - No COUNT query. - Better for
infinite scrolling.

Use Page: - Admin screens - Reports

Use Slice: - Feeds - Infinite scroll

5. Reverse Proxy

What is Reverse Proxy?

Receives requests from clients and forwards them to backend services.

Examples: - NGINX - HAProxy - Apache HTTP Server

Benefits

-   SSL termination
-   Load balancing
-   Caching
-   Security
-   Traffic routing

Reverse Proxy vs Load Balancer

Reverse Proxy: - Front door for services.

Load Balancer: - Distributes traffic across instances.

Modern tools often provide both.

6. Spring JPA and Hibernate

JPA

Specification.

Hibernate

Most popular JPA implementation.

Entity Lifecycle

-   Transient
-   Persistent
-   Detached
-   Removed

Cascade Types

    @OneToMany(
        mappedBy="order",
        cascade=CascadeType.ALL,
        orphanRemoval=true
    )
    private List<LineItem> items;

CascadeType.REMOVE: - Parent deleted -> Child deleted.

Fetch Types

EAGER: - Load immediately.

LAZY: - Load when accessed.

Prefer LAZY by default.

N+1 Problem

Problem: - One query for parent. - N queries for children.

Solutions: - Fetch Join - Entity Graph - Batch Fetching

Optimistic Locking

    @Version
    private Long version;

Prevents lost updates.

Pageable vs Slice

Important for performance-sensitive APIs.
